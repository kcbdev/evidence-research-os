# PBI-023: Adjudication writes confidence (kill the zeros)

## Directive

Live-fire (PBI-019) proved every claim carries `confidence: null` →
the table shows 0.00 and confidence filters are meaningless: NOTHING
in the pipeline writes confidence (extraction mints claims without
it, adjudication only sets status). Extend the judge protocol (same
judge call, no new spend): `STATUS <id>: <STATUS> | sq ms ic cl ov`
— five 0–1 floats (source_quality, methodological_strength,
independent_confirmation, contradiction_level, overall), space
separated, fixed order. Parse + clamp to [0,1]; a malformed confidence
segment voids ONLY the numbers (the status verdict still applies —
fail granular, not whole-line); a missing segment leaves confidence
untouched. The no-evidence guard still resolves INSUFFICIENT_EVIDENCE
with confidence None (nothing weighed → nothing scored — honest).
