# PBI-026: Approval modal shows what you're approving

## Directive

Live-fire (PBI-019): the checkpoint modal asks for a blank check —
no claim summary, no audit signal, no path to the evidence. Approval
without evidence contradicts the trust model. Before the Approve /
Reject buttons, the modal must render an approval dossier, all from
existing read endpoints (no backend changes): claims-by-status counts
(`GET .../claims`, aggregated client-side), total evidence + sources
(from the overview's existing detail payload or a second fetch),
and a prominent link opening the claims table (new tab safe).
Copy must state the semantic: "Approve = publish report.md built
from exactly these adjudicated claims. Reject = stop, publish
nothing." Tests: modal renders counts from a mocked claims payload;
link href correct; approve/reject behavior unchanged (existing tests
keep passing).
