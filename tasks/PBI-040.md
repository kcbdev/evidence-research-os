# PBI-040: Audits API + audit UI page

## Directive

Surface the Phase-3 audit results: `GET
/lab-projects/{id}/audits/latest` (optional PASS/WARNING/FAIL filter,
per (claim, evidence, stage) rows incl. `detail`) and `POST
/lab-projects/{id}/audits/rerun` (optional `claim_id` scope;
synchronous re-run per spec Decision, returns the fresh run id).
Build `/lab/[id]/audit`: table with per-stage badges, row-expand shows
the reasoning detail, FAIL/WARNING filters, per-claim + global re-run
buttons, claim links jumping to the trace modal. Audit badges in
`EvidenceTraceModal` link here filtered to the claim.
