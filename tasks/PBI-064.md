# PBI-064: Builder dependencies + shadcn component pull

## Directive

Install the builder's frontend dependencies and pull the shadcn
components it needs — tooling only, no UI code. Via Windows-native
invocation (`cmd /c "npm.cmd ..."` / `npx.cmd`, never POSIX sh):
`npm install` `@xyflow/react`, `react-hook-form`, `zod`, `sonner`,
`@uiw/react-md-editor`, `@codemirror/view`
(`@codemirror/lang-javascript` only if the minimal setup needs it;
`cmdk` only if the shadcn `command` pull does not bring it), then
`npx shadcn@latest add` each of: `sheet`, `command`, `dropdown-menu`,
`sonner`, `switch`, `textarea`, `checkbox`, `popover`, `accordion`,
`scroll-area`, `resizable`, `tooltip`, `form` (skip any already
vendored under `frontend/src/components/ui/`). Do not bulk-install
the library; do not touch any route, test, or config beyond what the
installers modify (`package.json`/lockfile + `components/ui/` +
documented css/token wiring if the `sonner` pull requires it).
