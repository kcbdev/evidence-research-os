# PBI-073: Run-start payload extensions (search_scope + pinned_sources)

## Directive

Implement the shippable halves of guide Tasks 49 and 58 (Steps 2 and 7).
In `backend/app/api/runs.py::start_run`: accept and validate `search_scope`
(`open_web | academic_only | peer_reviewed_only`, default `open_web`, 422
otherwise) and `pinned_sources` (optional list of source IDs; unknown IDs
404 fail-closed); record both on the run record. When `pinned_sources` is
set, seed the evidence graph from those sources directly and skip discovery
(the closed-corpus half of Task 58, which has a real seam). Frontend: add a
`Select` for search scope (default `open_web`) to `RunStartDialog.tsx`.
Per Spec D2, the result-filtering half of Task 49 and the tool-disabling
half of Task 58 have no seam (no search provider exists;
`methodology.tools.enabled` is schema-only) and are PBI-080 (Blocked) — this
card implements no filtering theater, and the recorded scope value is
documented as pending its filter.
