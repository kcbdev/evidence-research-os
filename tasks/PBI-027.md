# PBI-027: Modals follow dark mode (no white slabs)

## Directive

Live-fire (PBI-019): both modals render white panels (`bg-white`)
that clash with the dark control panel and wash out text. Every
overlay in the app must be dark-mode aware using Tailwind `dark:`
variants (the scaffold already themes pages this way — follow the
existing pattern, don't invent one): panel `dark:bg-zinc-900
dark:text-zinc-100`, body text `dark:text-zinc-400`
(or equivalent existing scale step), borders
`dark:border-zinc-700`, inputs `dark:bg-zinc-800`, backdrop unchanged
(`bg-black/50` works on both). Scope: `EvidenceTraceModal`,
`ApprovalModal` (grep for any other `fixed inset-0`/overlay in
`frontend/src` — if a third exists, include it). Tests: render each
modal with `class="dark"` on a wrapper and assert the dark classes
are present (class-level, not pixel-level — jsdom has no layout).
