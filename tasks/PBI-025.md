# PBI-025: Control-panel presentation pass

## Directive

Live-fire (PBI-019) UI polish, all cheap and local:
1. Uniform width: every page uses the same container
   (`max-w-4xl mx-auto p-8`) — today dashboard/overview/run are
   `max-w-3xl` while claims is `max-w-4xl`. Extract a shared
   `Page` shell component if it removes more duplication than it adds,
   else set the class consistently.
2. Better tabs (overview): real tablist semantics
   (`role=tablist/tab`, `aria-selected`), counts in labels
   (e.g. `Claims (23)`), and the active tab visually unambiguous.
3. Claims table UI: keep the structure, fix spacing/empty states
   (a filtered-to-zero table currently renders a bare header —
   show "No claims match these filters.").
4. Output tab: render the report as markdown, not `<pre>`. No new
   dependency: a minimal renderer for headings, bold, code spans,
   lists, and paragraphs (+ test). Anything fancier is out of scope.
