# PBI-070: Builder toolbar (validate/save/set-default/duplicate/export/import) + witness

## Directive

Close the builder: toolbar actions wired to the real backend plus a
human-gated end-to-end witness. Validate compiles client-side
(unknown refs, orphaned loop targets, judge/council overlap) without
saving and also calls `POST /methodologies/{id}/validate`; results
render as a `ValidationToastList` via Sonner (red errors, amber
warnings). Save persists and stays disabled until Validate passes.
Set-as-Default uses a confirm Dialog (this changes real run
behavior). Overflow `DropdownMenu` (`⋮`): Duplicate, Export YAML
(read-only Dialog with copy button), Import YAML (paste → parse into
canvas, same validation as builder-authored state). Then the witness
(human gate): compose one methodology entirely in the builder —
built-in stages + a library role + one AND-chained loop condition —
save, set as default on a scratch Lab Project, run it, and confirm
the custom stage in the event log and the loop behaving per its
condition. Scratch project only; production default untouched until
the human says otherwise.
