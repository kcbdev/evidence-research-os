# PBI-005: Coolify services + data volume

## Directive

Create the Coolify project per guide §0/plan task 2: `backend` service
(uvicorn, port 8000) + `frontend` service (Next.js, port 3000) +
persistent volume mounted at `/data/lab-projects` with
`LAB_PROJECTS_ROOT=/data/lab-projects` on the backend. Backend may
serve a placeholder response at this stage (real routers are Phase 1).
Infra-only PBI — no application code changes.

## Context

- Spec: `specs/phase-0-scaffold/spec.md`
- Depends on: PBI-001
- Files/modules touched: Coolify project config only (no repo files
  except optional `docker/*` if the chosen deploy path needs them —
  prefer Coolify-native builds)
- Plane: none

## Verification

- Spec `Contracts`: both services healthy in Coolify; a file written
  under the volume path survives a backend redeploy (mount proof).
- Manual step (human gate): open both service URLs, confirm reachability.

## Refinement rule

- If reality diverges from the spec (e.g. volume mount path differs on
  the target host): stop, flag for human review — the mount path is a
  load-bearing contract for every later PBI.
