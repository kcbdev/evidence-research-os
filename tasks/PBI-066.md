# PBI-066: Builder canvas shell (stage nodes + sequential edges + round-trip)

## Directive

Build `/settings/methodologies/[id]/builder` as a working canvas for
the simplest case only: header (inline-editable name, Compatible-modes
badge + adder), left vertical shadcn `Tabs` (Workflow renders the
canvas; Roles/Tools/Budget/Metadata tabs are placeholder panels
pointing at PBI-069 — no dead controls), React Flow canvas with
`StageCard` custom nodes for built-in `NODE_REGISTRY` stages only
(icon + name), drag-to-connect sequential edges (solid), floating `+`
button opening the `NodePalette` `CommandDialog` (Cmd+K bound;
built-in stages section only — role/custom-code sections are
PBI-067), node click opening an empty inspector `Sheet` (resizable;
content arrives in PBI-067/068), and Save loading/saving through the
existing methodology API (`GET/PUT /methodologies/{id}`) so that
canvas → YAML → `build_graph_from_methodology` round-trips on a
sequential-only methodology. No loop-back handles, no conditions, no
role/custom-code nodes, no toolbar beyond a minimal Save in this PBI.
Canvas tests are RTL + jsdom (mock ResizeObserver at the test setup
level — check existing component tests for DOM-API precedent before
reaching for Playwright).
