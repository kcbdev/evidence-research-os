# PBI-024: Runs history (endpoint + overview tab)

## Directive

Live-fire (PBI-019): the overview Runs tab offers only "Start run" —
past runs are unreachable except by bookmarked URL. Add `GET
/api/v1/lab-projects/{id}/runs` listing the in-memory registry for
that project: `[{run_id, status, needs_approval, events_count,
error}]` (newest first). Document the MVP limitation in the handler
docstring: the registry is process memory, so history vanishes on
backend restart (checkpoints persist, records don't — already
documented in runs.py). Overview Runs tab: start button RETAINED on
top, history list below (status badge + event count + link to the run
view). Tests: start two runs → list shows both newest-first; unknown
project → 404 (reuse `_store`, no mkdir side effect).
