# PBI-020: Archive Lab Project (DELETE surface)

## Directive

Spec §8 lists `DELETE /lab-projects/{id}` ("Archive — never hard-delete
without confirmation"). It has no home: PBI-014 closed without it and
PBI-015 owns read-model routers. Implement archive semantics: a
reversible archive flag (exact mechanism free — metadata marker,
`.archived` sentinel, or router-level filter — but it must survive
a rebuild and must NOT delete history), `DELETE` sets it (confirm
semantics), archived projects vanish from `GET /lab-projects` by
default, `GET /lab-projects/{id}` still serves them with an
`archived: true` marker. Tests: archive → disappears from list →
detail still serves → second DELETE is idempotent.
