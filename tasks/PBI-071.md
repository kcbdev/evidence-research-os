# PBI-071: Concurrent targeted_research

## Directive

Parallelize the `make_targeted_research` factory in
`backend/app/graph/nodes.py` so open contradiction tasks dispatch
concurrently (guide Task 46, Step 1). Keep everything else identical:
Tier-2/Tier-3 prior-art context enrichment per task, per-dispatch
`call_model_resilient` with attempts charged via the PBI-007 helpers on a
copy, one round consumed, `pending_tasks` cleared, debate transcripts per
task id. Per Spec D1, do NOT create `app/agents/{scientist,investigator,
skeptic}.py` — the guide's sketch references modules that do not exist; the
factory body is the seam. Concurrency primitive is the implementer's choice
(`asyncio.gather` via `asyncio.run` inside the sync node, or a thread pool),
but debate-file writes and budget accounting stay exactly-once under
concurrency.
