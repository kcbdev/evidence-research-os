# PBI-017: Claims table + EvidenceTraceModal

## Directive

Build `/lab/[id]/claims` per guide §6.3 and spec §9: filterable/sortable
claims table (status, confidence, contradiction flag) fed by
`GET .../claims`, row click opens `EvidenceTraceModal`
(claim → evidence → source → original location, via
`GET .../claims/{id}`), plus `ClaimConfidenceBar` (5-dimension
breakdown, never a single number) and `ContradictionBadge` linking to
the targeted-research task where one exists.
