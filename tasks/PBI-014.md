# PBI-014: Lab-projects + runs API (SSE + approve)

## Directive

Implement `backend/app/api/` routers per guide §5.1–5.2 and spec §8:
`POST/GET /lab-projects`, `GET /lab-projects/{id}`,
`POST .../runs` (validates model assignment, seeds the initial state's
budget from the project's `project.yaml` (PBI-007 contract), builds graph,
returns run_id), `GET .../runs/{run_id}`, `GET .../stream` (SSE via
sse-starlette, live node transitions), `POST .../approve` (LangGraph
resume). Wire `app/main.py`. TestClient tests cover CRUD + approve
resume; SSE tested with an async client asserting first-node events
arrive (no timing flakes — bound the wait).
