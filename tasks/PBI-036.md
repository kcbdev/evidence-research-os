# PBI-036: Ideas API (list, filter, PATCH status/promote)

## Directive

Expose ideas over HTTP per the API Reference: `GET
/lab-projects/{id}/ideas` (optional `status` filter) and `PATCH
/lab-projects/{id}/ideas/{idea_id}` accepting `promoted_to_claim` or
`rejected`. Promoting creates a new `Claim` referencing the idea
(`supporting_sources: []`, status `INSUFFICIENT_EVIDENCE`, statement
carried over with idea link) and returns `created_claim_id`; any other
status value 422s; unknown idea 404s. New router module mounted in
`main.py` beside the existing three. Store layer already exists
(`write_idea/list_ideas`) — do not touch it.
