# PBI-021: Task deep-link surface (badge button + modal section)

## Directive

Tech Spec §9.2 wants claim→task links, but no task surface exists
(no /tasks route, no task view) and the claims view returns no task
id — so an href would be a dead promise. Accepted interpretation
(recorded here, not silently assumed): the badge is a BUTTON opening
the claim's trace modal, and the modal's Linked-tasks section (stable
`task-<id>` anchors) IS the surface. Add a minimal tasks read
endpoint (GET .../tasks, filterable by claim_id) matching on the
`T-<claim-id>` convention OR the claim statement embedded in the
task question; render id/agent/question/reason (+sources when set)
in the modal with empty + fetch-failure states that leave the trace
standing alone.
