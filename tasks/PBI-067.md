# PBI-067: Role nodes + Custom Code nodes on the canvas

## Directive

Extend the PBI-066 canvas with the two remaining node types. `RoleCard`
(persona icon + role name + model-name and tool-count badges):
placement via the palette's new "Custom Roles" section (populated
from the PBI-065 Roles library) plus "Create new custom role" entry
that closes the palette and opens the PBI-065 Role editor in a Dialog,
auto-adding the saved role to the canvas; inspector (Sheet) gets the
library-entry Combobox (built-ins + library in one list), model
inherit-with-override Switch revealing a model Combobox, same override
pattern for tools, and an "Edit this role" link opening the Role
editor with a Tooltip warning that edits affect all referencing
methodologies. `CustomCodeCard` (code icon + filename + muted
"Authored in code" Badge): palette's "Custom Code (discovered)" section
lists `custom_nodes/*.py` entries; inspector is a read-only Card
(filename, `NODE_ID`, docstring description, copy-path button). Both
node types serialize into the existing `methodology-graph.ts`
canvas↔YAML mapping using only Phase 5b-accepted keys (`custom_roles`
refs, Tier C names) — no mapping the compiler cannot already compile.
